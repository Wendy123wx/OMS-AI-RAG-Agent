### 1.3 假设与约束

1. **角色层级**：系统仅区分「普通用户」与「管理员」两级，不设超级管理员等更细角色。
2. **账号开通**：正式账号由管理员在用户管理中新增后即可登录；不要求首次登录强制改密。
3. **登录方式**：本期仅实现账号密码登录；钉钉扫码登录在登录页保留占位入口，不做实际对接开发。
4. **问答模式**：支持同一问答会话内的上下文连续追问；超出上下文边界后自动压缩或清空更早对话（见 5.3.3）。
5. **留痕规则**：仅「已完成」的问答交互写入历史/查询记录；发送前取消、生成中终止的不留痕。
6. **知识库**：业务知识文档由外部维护，本期不做知识库上传/编辑；问答模块预留对接外部知识库的检索能力。
7. **订单类问题**：涉及具体订单实时信息的提问，通过调用外部订单查询接口获取答案，不走静态知识库检索。
8. **历史/查询记录**：只读，用户与管理员均不可删除或修改留痕内容本身；管理员对用户账号的禁用/删除操作单独记入操作记录。
9. **演示项目**：登录页在所有环境均展示测试账号信息，便于演示验收。

## 2. 背景与问题

在 OMS（订单管理系统）相关业务场景中，用户经常需要查阅业务文档、规范或知识资料来获取问题答案。传统人工检索效率较低，且答案缺少可追溯的文档来源，核实成本高、可信度不足。同时，部分问题（如具体订单状态）需要实时查单，无法仅靠静态文档回答。

随着使用人数增加，需要统一的身份认证、使用记录留存与后台管理能力，以便：

- 用户能够方便地登录系统，并追溯自己历史提过的问题；
- 管理方能够管理普通用户账号，掌握系统整体使用情况，以及用户高频关注的问题方向。

**产品定位**：OARA 是一套面向 OMS 业务场景的智能问答系统。用户通过问答获取业务知识或订单实时信息，并看到答案来源；支持会话内连续追问；同时具备基础账号体系、本人历史记录留存，以及面向管理员的用户管理与使用分析能力。

## 4. 需求目标

1. 为用户提供安全、便捷的身份认证，保障系统访问可控。
2. 为用户提供基于业务知识文档与订单实时查询的智能问答，使其快速获得答案，并可追溯所依据的文档来源或查单结果，提升获取效率与答案可信度。
3. 使用户能够在同一会话内连续追问，并回溯本人历史提问，避免重复提问，便于复查完整问答内容。
4. 使管理员具备对普通用户账号的管理能力，保障账号体系可维护（例如禁用异常账号、追溯删除等操作）。
5. 使管理员掌握系统整体使用情况，并了解用户高频关注的问题方向，为后续运营与知识完善提供参考。

## 5. 功能范围（做什么）

### 5.1 登录与身份认证

- 未登录用户需先完成身份认证，方可使用系统能力。
- **账号密码登录**（本期实现）：用户输入账号和密码完成登录。
- **钉钉扫码登录**（本期占位）：登录页保留钉钉扫码登录入口与视觉占位，点击后提示「功能开发中」或等价说明，不对接钉钉身份体系，不做实际开发。
- 登录页初始化时展示账号密码提示信息；**所有环境均展示**，不区分演示/正式环境（当前为演示项目）。
- 提供测试账号供验收/演示：管理员 `admin`、普通用户 `user`（密码均为 `12345678`）。
- 正式账号由管理员在用户管理中新增后，使用所设初始密码即可登录；**不要求**首次登录强制修改密码。
- 登录成功后进入工作台。

### 5.2 工作台

登录后的统一使用入口，包含三类能力：

- **问答平台**：所有登录用户均可使用。
- **历史记录**：所有登录用户均可使用，且仅能看到本人记录；页面为列表，点击某条记录弹窗展示详情（见 5.4）。
- **管理后台**：仅管理员可见、可进入；普通用户不可见该入口。

**全局导航**

- 工作台右上角展示用户头像；点击头像展开下拉菜单，包含「修改密码」「退出登录」入口（见 5.8）。
- 管理员从管理后台可返回工作台，继续使用问答或查看本人历史记录。

### 5.3 智能问答（问答平台）

#### 5.3.1 基本问答

- 用户输入问题并发送后，系统给出对应答案。
- 答案须展示所依据的信息来源：
  - **常规业务问题**：通过外部知识库检索获得答案，并展示文档检索路径（来源）；
  - **订单类问题**：通过调用外部订单查询接口获得答案，并展示查单结果来源说明（如「订单系统实时查询」）。
- 发送前，用户可取消本次发送。
- 发送后、答案仍在生成过程中，用户可终止（停止生成）。
- **取消发送**与**终止生成**的交互均**不写入**历史记录与查询记录（见 1.3 假设 5）。
- 普通用户与管理员均可使用问答能力。

**订单类问题判定（业务口径）**：用户提问涉及具体订单号、订单状态、物流信息等需实时查单的内容时，走订单查询接口；其余业务规范、流程、政策类问题走知识库检索。

#### 5.3.2 上下文连续追问

- 同一问答会话内，用户可基于上一轮问答结果继续追问，系统结合当前会话上下文作答。
- 用户可主动「新建会话」清空当前上下文，从零开始提问。
- 上下文边界与溢出策略见 5.3.3。

#### 5.3.3 上下文边界

- 系统为每个问答会话维护有限长度的对话上下文。
- **保留策略**：默认保留最近 **10 轮**问答（1 轮 = 1 次用户提问 + 1 次系统作答）；实现阶段可按 token 上限等价换算，但用户侧感知为「最近若干轮对话」。
- **超出边界时的处理**（按顺序执行）：
  1. **压缩**：对超出保留轮次的更早对话自动生成摘要，摘要在后续问答中作为压缩上下文参与理解；
  2. **清空**：若压缩后仍超出上限，则清空全部历史上下文，并在问答区域提示：「对话上下文已重置，请重新描述您的问题。」
- 被清空或压缩前的完整交互内容，若已完成作答，仍按 5.4 规则写入历史记录。

#### 5.3.4 问答异常与边界

系统在下列场景须给出明确、专业的提示，**不展示虚假来源路径**：

| 场景 | 用户可见提示（固定文案） |
| --- | --- |
| 与 OMS 业务无关的问题 | 系统提示：该问题暂时无法回答 |
| 知识库未检索到相关内容 | 未找到相关业务文档，请尝试换个问法或联系管理员补充知识库。 |
| 知识库检索服务异常 | 文档检索暂时不可用，请稍后重试。 |
| 订单查询接口未返回有效结果 | 未查询到相关订单信息，请核对订单号后重试。 |
| 订单查询接口调用失败 | 订单查询暂时不可用，请稍后重试。 |
| 答案生成失败 | 答案生成失败，请稍后重试。 |

上述异常交互若已完成（即系统已返回上述提示作为最终答复），计入「回答异常量」统计（见 5.6），并写入历史/查询记录。

### 5.4 历史记录查询

- 记录当前登录用户本人发起且**已完成**的查询（含管理员本人的提问，不含他人记录；不含取消/终止的交互）。
- 页面形式为**列表页**；列表每条展示：**问题摘要、记录时间、来源路径**（不展示完整答案正文）。
- 用户点击某条记录，以**弹窗**展示详情，内容包括：**完整问题、记录时间、来源路径、完整答案正文**。
- 历史记录仅支持查看，用户不能删除、不能修改。

### 5.5 用户管理（管理后台，仅管理员）

#### 5.5.1 普通用户信息

管理员可对**普通用户**账号进行新增、查看、修改、删除。普通用户账号信息包含：

| 字段 | 说明 | 备注 |
| --- | --- | --- |
| 用户名 | 登录账号，唯一标识 | 新增时必填 |
| 用户邮箱 | 联系邮箱 | 管理员可修改 |
| 用户头像 | 展示用头像 | 支持设置/更新 |
| 状态 | 正常 / 禁用 | 见 5.5.2 |
| 创建时间 | 账号创建时间 | 系统自动记录 |
| 更新时间 | 最近一次信息变更时间 | 系统自动记录 |

用户管理不包含对管理员账号的增删改。

#### 5.5.2 禁用与删除

| 操作 | 规则 |
| --- | --- |
| **禁用** | 可恢复（管理员可将状态改回「正常」）；禁用后该账号**无法登录**；用户列表即时刷新展示最新状态与操作时间；该用户的历史查询记录在本人侧与管理员「查询记录」中**均保留**。 |
| **删除** | **不可恢复**；执行前须**二级确认**；删除后该账号**不存在**，尝试登录时提示账号不存在并拦截；该用户的历史查询记录在查询记录模块中**保留**；删除操作记入操作记录（见 5.5.3）。 |

#### 5.5.3 操作记录

- 管理员对用户执行的**禁用、删除**等关键操作均写入操作记录。
- 用户管理模块**右上角**提供「历史操作」入口，管理员可查看操作记录列表，内容包括：操作类型、目标用户、操作时间、操作人。
- 被删除用户的相关信息从用户列表移除，但其删除操作可在历史操作中追溯。

### 5.6 统计看板（管理后台，仅管理员）

展示系统整体使用情况的统计数据，包含以下指标：

| 指标 | 说明 |
| --- | --- |
| 提问总量 | 系统累计收到的已完成问答次数（含正常答复与异常提示类答复） |
| 回答异常量 | 累计返回异常提示类答复的次数（见 5.3.4 各异常场景） |
| 近 7 天趋势 | 以日为粒度展示近 7 天提问量变化趋势 |
| 活跃用户数 | 近 7 天内有至少 1 次已完成问答的去重用户数 |

### 5.7 查询记录管理（管理后台，仅管理员）

- 展示系统内**所有普通用户**的已完成查询记录（与「历史记录」的差异：历史记录只看本人，此处看全体普通用户）。
- 提供**搜索**能力：管理员可按问题关键词搜索查询记录（本期不做按用户、时间范围的筛选，见 1.3 假设及第 9 节）。
- 列表每条展示：提问用户、问题摘要、记录时间、来源路径；点击可弹窗查看**完整问题、记录时间、来源路径、完整答案正文**（与用户侧历史详情对齐）。
- **高频搜索词**展示规则：
  - 对普通用户查询记录中的问题文本进行分词统计；
  - 统计周期：**全量**累计；
  - 搜索/点击次数**排名前三**的词并列展示在**第一排**；
  - 其余词汇按点击次数降序排列，并展示各词的点击次数；
  - 若第三名并列，则并列项均纳入第一排展示。
- 管理员本人的提问出现在管理员自己的历史记录中，**不计入**本模块的普通用户查询记录及高频搜索词统计。

### 5.8 通用账户功能

#### 5.8.1 修改密码

- 用户通过工作台右上角头像下拉菜单进入「修改密码」。
- 以**单独弹窗**形式展示，包含字段：**用户名**（只读展示当前用户）、**原始密码**、**新密码**、**确认密码**。
- 用户填写完毕点击「确定」，校验通过后密码修改成功并提示；须输入正确的原始密码方可修改（用户**自助**，管理员不代改）。
- 密码修改成功后，不强制退出登录；用户可继续使用或自行退出。

#### 5.8.2 退出登录

- 用户通过头像下拉菜单选择「退出登录」；退出后需重新认证才能使用系统。

### 5.9 权限与导航

#### 5.9.1 管理后台布局

- **左侧**：菜单栏，包含「用户管理」「统计看板」「查询记录」三个菜单项。
- **右侧**：内容区域，点击左侧菜单切换右侧为对应功能页面。
- 管理后台**右上角**提供「返回」入口，管理员可回到工作台。

#### 5.9.2 权限边界

- 管理后台仅管理员可见和可访问，普通用户不可见、不可进入。
- 普通用户无法通过任何入口访问管理后台功能。

## 6. 不涉及范围（Out of Scope）

- **知识库文档**的上传、编辑、维护及审核流程（本期外置，问答模块预留对接外部知识库的检索接口；知识库建设与维护纳入后续版本或外部系统）。
- **钉钉登录**的实际对接开发（本期仅保留登录页占位入口）。
- 多语言/国际化支持。
- 移动端专属应用（App）。
- 除「管理员 / 普通用户」外的更多角色层级或细粒度权限。
- 消息通知/推送。
- 历史记录、查询记录、统计数据的导出。
- 除本 PRD 已定义指标与高频词展示外的更复杂数据分析、报表下钻。
- 钉钉登录以外的其他第三方账号体系（如企业微信、飞书等）。
- 管理员对管理员账号的管理。
- 查询记录按用户、时间范围的筛选（本期不做；搜索见 5.7）。
- 首次登录强制改密、用户自助找回密码（忘记密码）流程。

## 7. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 安全传输 | 生产部署须通过 HTTPS 提供访问，避免明文传输账号密码与问答内容。 |
| 密码存储 | 用户密码不得以明文存储；须采用业界通用的单向哈希等方式保存（实现细节不在本文档范围）。 |
| 登录态 | 用户登录成功后维持会话；会话过期或退出登录后须重新认证。具体过期时长实现阶段确定，默认建议 8 小时无操作过期。 |
| 可用性 | 核心路径（登录、问答、查看历史）应保证演示环境下稳定可用；外部知识库/订单接口不可用时的降级表现见 5.3.4。 |
| 性能 | 演示项目不设严格 SLA；问答首字响应与完整生成时长依赖外部模型与检索服务，本期不做硬性指标约束。 |

## 8. 使用场景/业务流程

1. **登录场景**：用户打开系统，使用账号密码完成认证（或看到钉钉占位入口），进入工作台。
2. **常规问答场景**：用户提出业务规范类问题，系统从知识库检索并返回答案及文档来源路径；用户可继续追问，直至上下文达到边界被压缩或重置。
3. **订单问答场景**：用户提出涉及具体订单的问题，系统调用订单查询接口返回答案及查单来源说明。
4. **问答异常场景**：用户提出无关问题或检索/查单/生成失败时，系统返回 5.3.4 约定的固定提示文案。
5. **取消/终止场景**：用户发送前取消或生成中终止，本次交互不留痕。
6. **普通用户查历史场景**：用户在历史记录列表浏览本人记录（见问题摘要、时间、路径），点击某条弹窗查看完整问答详情。
7. **管理员提问与回看场景**：管理员同样可提问、查看本人历史记录；需要运营管理时进入管理后台。
8. **管理员管理用户场景**：管理员进入用户管理，新增/查看/修改普通用户（含邮箱、头像等），或禁用（可恢复）/删除（二级确认、不可恢复）账号；必要时查看右上角历史操作记录。
9. **管理员查看统计场景**：管理员查看统计看板中的提问总量、回答异常量、近 7 天趋势、活跃用户数。
10. **管理员查看全局查询记录场景**：管理员搜索或浏览全体普通用户的查询记录，查看高频词前三并列置顶及其余词汇的点击次数排序。
11. **返回工作台场景**：管理员在管理后台点击返回，回到工作台继续使用问答或历史记录。
12. **账户维护场景**：用户通过头像下拉修改密码（弹窗输入原密码与新密码）或退出登录。

## 9. 验收标准

验收标准按功能模块分组；涉及已关闭的开放问题时，在括号内标注原条目编号。

### 9.1 登录与身份认证（原 D2、D3、B10）

1. 未登录不能使用工作台能力。
2. 账号密码登录可用；测试账号 `admin / 12345678`、`user / 12345678` 均可正常登录并进入对应角色范围。
3. 登录页在所有环境展示测试账号提示信息。
4. 钉钉登录入口可见但不可用，点击后给出「功能开发中」类提示，不要求完成真实扫码登录。
5. 管理员新增的正式账号可使用初始密码直接登录，不要求首次强制改密。

### 9.2 工作台与导航（B9）

6. 登录成功后进入工作台；普通用户可见问答与历史记录，不可见管理后台；管理员 additionally 可见管理后台入口。
7. 工作台右上角头像下拉包含「修改密码」「退出登录」。
8. 管理后台为左侧菜单 + 右侧内容布局；菜单含用户管理、统计看板、查询记录；右上角可返回工作台。

### 9.3 智能问答（B4、B5、D5、D6、E2）

9. 常规业务问题走知识库检索，答案附带文档来源路径。
10. 订单类问题走订单查询接口，答案附带查单来源说明。
11. 同一 session 内可基于上下文连续追问；超出 10 轮后触发压缩或清空策略并有用户可感知提示。
12. 用户可主动新建会话清空上下文。
13. 发送前可取消；生成中可终止；取消与终止均不写入历史/查询记录。
14. 各异常场景返回 5.3.4 约定的固定提示文案；业务无关问题返回「系统提示：该问题暂时无法回答」。

### 9.4 历史记录（B8、D7、B5）

15. 普通用户只能看到本人已完成的历史记录列表；列表展示问题摘要、时间、来源路径。
16. 点击列表项弹窗展示完整问题、时间、来源路径、完整答案。
17. 历史记录不可删除、不可修改。
18. 取消/终止的交互不出现在历史列表中。

### 9.5 用户管理（B1、B2、D11）

19. 管理员可对普通用户完成新增、查看、修改、删除及禁用；不能管理管理员账号。
20. 普通用户信息含用户名、邮箱、头像、状态、创建时间、更新时间；管理员可修改邮箱等信息。
21. 禁用后用户无法登录；禁用可恢复为正常；列表展示最新状态与操作时间。
22. 删除须二级确认，删除后不可恢复；删除账号无法登录且提示账号不存在。
23. 禁用/删除操作可在用户管理右上角「历史操作」中追溯；删除用户的历史查询在查询记录中保留。

### 9.6 统计看板（B6）

24. 统计看板展示：提问总量、回答异常量、近 7 天趋势、活跃用户数四项指标。

### 9.7 查询记录管理（B7、C3、D10、D12）

25. 管理员可查看所有普通用户的查询记录，含提问用户、问题、时间、来源；可弹窗查看完整答案。
26. 提供按问题关键词的搜索能力；不要求按用户、时间筛选（原 D12：本期不做）。
27. 高频搜索词：全量分词统计，前三并列置顶第一排，其余按点击次数降序并展示次数。
28. 管理员本人的提问不计入普通用户查询记录与高频词统计。

### 9.8 通用账户功能（B3、D8）

29. 用户可通过头像下拉打开修改密码弹窗，填写用户名（只读）、原始密码、新密码、确认密码后完成修改。
30. 用户可正常退出登录；退出后需重新登录。
