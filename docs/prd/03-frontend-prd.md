## 2. 角色与导航总览

### 2.1 未登录用户

- 登录页（P01）

### 2.2 普通用户（登录后）

- **问答平台壳层**（登录后统一框架，顶栏 Tab 切换）
  - 工作台 Tab → 问答平台页（P02，默认激活）
  - 历史记录 Tab → 历史记录列表页（P03-01）
    - 「查看」→ 历史记录详情页（P03-02 / C01，弹窗）
  - 管理后台 Tab：**不可见**（PRD 5.9.2）
- 头像下拉 → 修改密码（P08）/ 退出登录

### 2.3 管理员（登录后）

- **问答平台壳层**
  - 工作台 Tab → P02
  - 历史记录 Tab → P03-01（仅本人记录）→ P03-02 详情
  - 管理后台 Tab → 进入**管理后台壳层**
- **管理后台壳层**（仅管理员）
  - 左侧菜单：用户管理（P04-01）| 统计看板（P06）| 查询记录（P07-01）
  - P04-01：含新增/编辑表单（C02 整合）；删除 → P04-02；右上角「历史操作」→ P05
  - P07-01：列表「查看」→ P07-02 详情（C04，弹窗）
  - 右上角「← 返回工作台」→ 回到问答平台壳层（P02）
- 修改密码（P08，全局弹窗）

说明：P03-02（C01，本人历史详情）与 P07-02（C04，管理员全量查询详情）业务视角、数据权限、使用主体完全独立，不可合并。

## 3. 布局容器与分区结构

系统存在三个布局容器，子页面挂载于对应容器的内容区。

### 3.1 登录页容器（P01）

```
┌─────────────────────────────────┐
│  [ 钉钉登录 ] [ 账号密码登录 ]    │  ← 顶栏 Tab 切换登录方式
├─────────────────────────────────┤
│  Tab 内容区：                     │
│  · 钉钉登录：二维码占位区          │
│  · 账号密码：账号输入 / 密码输入   │
│              [ 登录 ]            │
│  · 测试账号提示信息区（PRD 5.1）   │
└─────────────────────────────────┘
```

- 两种登录方式通过**顶栏 Tab**切换展示（PRD 5.1）；钉钉 Tab 为占位，点击提示「功能开发中」。
- 账号密码 Tab 为本期唯一可建立登录会话的方式。

### 3.2 问答平台壳层（P02 / P03-01 共享框架）

登录成功后进入；P02 与 P03-01 共用同一顶栏框架，通过 Tab 切换右侧内容区。

```
┌──────────────────────────────────────────────────────────┐
│ 问答平台    [ 工作台* ] [ 历史记录 ] [ 管理后台† ]    (头像) │
├──────────────────────────────────────────────────────────┤
│  内容区（随 Tab 切换）：                                    │
│                                                          │
│  * 工作台 Tab（P02）：                                    │
│    ┌─────────────────────────────┐                       │
│    │  回答区域（多轮问答展示）      │                       │
│    └─────────────────────────────┘                       │
│    ┌─────────────────────────────┐                       │
│    │  提问区域          [ 发送 ]  │                       │
│    └─────────────────────────────┘                       │
│                                                          │
│  * 历史记录 Tab（P03-01）：                               │
│    ┌ 问题摘要 ─── 来源路径 / 记录时间 ── [ 查看 ] ┐       │
│    ├ 问题摘要 ─── 来源路径 / 记录时间 ── [ 查看 ] ┤ 列表  │
│    └ ...（列表页，中间可滚动/分页）                ┘       │
│                                                          │
│  † 管理后台 Tab：仅管理员可见，点击进入 3.3 管理后台壳层    │
└──────────────────────────────────────────────────────────┘
```

- 顶栏右侧**头像**：下拉含「修改密码」「退出登录」（PRD 5.2、5.8）。
- 「管理后台」Tab 对普通用户**不可见、不可访问**（PRD 5.9.2）。
- P03-01 列表项点击「查看」或整行点击，以弹窗打开 P03-02 详情（PRD 5.4）。

### 3.3 管理后台壳层（P04 / P05 / P06 / P07 共享框架）

仅管理员通过问答平台顶栏「管理后台」Tab 进入。

```
┌──────────────────────────────────────────────────────────┐
│ 管理后台                          ← 返回工作台            │
├──────────┬───────────────────────────────────────────────┤
│ 用户管理  │  右侧内容区（随左侧菜单切换）：                  │
│ 统计看板  │                                               │
│ 查询记录  │  · 用户管理（P04-01）：用户列表 + 增删改查禁用   │
│          │    右上角「历史操作」→ P05                       │
│          │  · 统计看板（P06）：四项统计指标 + 近7天趋势       │
│          │  · 查询记录（P07-01）：高频词 + 搜索 + 记录列表   │
│          │    列表项 [ 查看 ] → P07-02 详情弹窗              │
└──────────┴───────────────────────────────────────────────┘
```

- 左侧菜单三项与 PRD 5.9.1 一致：**用户管理、统计看板、查询记录**（布局简图「问答记录」对应 PRD「查询记录」）。
- 右上角「返回工作台」回到问答平台壳层，默认激活工作台 Tab（P02）（PRD 5.2、5.9.1）。
- 统计看板仅展示 PRD 5.6 规定的四项指标，不扩展简图中未纳入 PRD 的其他指标。

## 5. 页面关系与导航路径

### 5.1 文字描述

1. 未登录 → P01（Tab 切换钉钉占位 / 账号密码登录）→ 成功进入问答平台壳层，默认 P02。
2. 问答平台壳层顶栏 Tab：工作台 ↔ 历史记录；管理员另可点「管理后台」Tab 进入管理后台壳层。
3. P03-01 列表点击「查看」→ P03-02 详情弹窗；P07-01 列表点击「查看」→ P07-02 详情弹窗；二者独立不可合并。
4. 管理后台壳层：左侧菜单切换 P04-01 / P06 / P07-01；P04-01 删除 → P04-02；「历史操作」→ P05；「返回工作台」→ P02。
5. 问答平台壳层头像下拉 → P08 修改密码或退出登录；管理后台内头像下拉见 Q4。
