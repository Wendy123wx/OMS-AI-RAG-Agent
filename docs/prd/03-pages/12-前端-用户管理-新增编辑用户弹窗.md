## 2. 页面定位与目标

承载"管理员新增或修改普通用户账号信息"的目标（PRD 5.5.1）。同一弹窗组件以两种模式呈现：新增模式创建可登录账号并设置初始密码；编辑模式修改邮箱、头像等可变更字段。与删除确认弹窗（C03）分离维护（`docs/meeting/20260909-页面布局概述.md`：C02 可整合至模块统一管理，本 PRD 独立描述三级弹窗业务规则，由 P04-01 触发）。

## 3. 使用角色与权限

- 仅管理员可访问（PRD 3、5.9.2）。
- 仅可作用于「普通用户」角色账号（PRD 5.5.1、9.5.19）。

## 4. 进入路径与导航关系

- **入口**：P04-01 点击「新增」打开新增模式；点击某行「编辑」打开编辑模式并带入目标用户数据。
- **离开路径**：提交成功或取消/关闭后回到 P04-01；成功后列表即时刷新。

## 5. 页面结构

1. **弹窗标题区**：区分「新增用户」/「编辑用户」模式。
2. **表单区**：见 6.1，按模式展示不同字段与可编辑性。
3. **操作区**：确定提交、取消/关闭。

### 6.1 表单字段（按模式）

**新增模式**：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 用户名 | 登录唯一标识 | 是 |
| 用户邮箱 | 联系邮箱 | 否 |
| 用户头像 | 展示用头像 | 否 |
| 初始密码 | 新增账号登录凭证 | 是（见总览 Q1） |

**编辑模式**：

| 字段 | 可编辑 |
| --- | --- |
| 用户名 | 否（只读展示） |
| 用户邮箱 | 是 |
| 用户头像 | 是 |

## 6. 关键组件清单

- 模式切换（新增/编辑）、表单字段输入、头像设置入口、提交与取消操作、校验结果提示

## 7. 页面状态

- 新增初始态、编辑初始态、提交中态、校验失败态、提交成功态、取消态

## 8. 核心交互流程

1. 管理员在 P04-01 点击「新增」或某用户「编辑」。
2. 打开本弹窗，按模式展示对应字段。
3. 新增：填写用户名、邮箱、头像、初始密码，提交 → 创建普通用户账号，刷新列表，关闭弹窗。
4. 编辑：修改邮箱/头像，提交 → 更新 `updatedAt`，刷新列表，关闭弹窗。
5. 取消 → 不保存，回到 P04-01。

## 9. 展示的业务数据

- 新增：`UserAccount` 待创建字段、`Credential`（初始密码）、`Role`（固定普通用户）
- 编辑：`UserAccount.username`（只读）、`Email`、`Avatar`、`updatedAt`

## 10. 业务规则与约束

- 不含管理员账号管理（PRD 9.5.19）。
- `username` 系统内唯一（领域模型 3.1 不变量2）；新增时重复须拦截。
- 正式账号新增后可使用初始密码直接登录，不要求首次强制改密（PRD 1.3 假设2、9.1.5）。
- 编辑不涉及密码修改（改密走 P08 修改密码弹窗，用户自助）。

## 11. 异常与边界场景

- 用户名重复、必填项为空、提交失败提示；取消不保存。
