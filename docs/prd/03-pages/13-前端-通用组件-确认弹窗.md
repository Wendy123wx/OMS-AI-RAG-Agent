# 页面PRD：确认弹窗（通用）

## 1. 页面信息

| 项目 | 内容 |
| --- | --- |
| 文件序号 | 13 |
| 页面编号 | G01 |
| 页面名称 | 确认弹窗（通用） |
| 弹窗类型 | **通用弹窗**（跨模块复用的确认交互容器，无固定业务字段） |
| 所属模块 | 通用组件 |
| 所属功能模块 | 不直接对应单一 PRD 功能点；为各业务确认类交互提供统一交互模式 |
| 可访问角色 | 按调用方上下文决定（本组件本身无独立入口） |

| 典型调用方 | 实现 C03 删除确认弹窗时可复用本组件布局；未来其他需「确认/取消」的二值决策场景 |

## 2. 页面定位与目标

提供系统内统一的「确认 / 取消」二值决策交互容器。仅承载可配置的标题、说明文案与按钮文案，**不包含**特定业务实体字段。业务专属内容（如待删用户名、不可恢复提示）须由私有化弹窗（如 C03）自行组织，不可将通用确认弹窗直接当作删除确认弹窗使用。

## 3. 使用角色与权限

- 无独立访问入口；由父页面或业务弹窗在需要用户二次确认时调用。
- 权限校验由调用方负责，本组件不感知角色。

## 4. 进入路径与导航关系

- **入口**：业务代码调用打开，传入标题、说明、确认/取消按钮文案及回调。
- **离开路径**：用户点击确认或取消/关闭后关闭弹窗，执行对应回调，回到调用方上下文。

## 5. 页面结构

1. **标题区**：可配置标题文案。
2. **说明区**：可配置正文说明（纯文本或简单插槽，不含复杂业务表单）。
3. **操作区**：确认按钮、取消/关闭按钮（文案可配置）。

## 6. 关键组件清单

- 可配置标题、说明文案、确认/取消按钮、关闭操作、遮罩层

## 7. 页面状态

- 关闭态、展示态、确认提交中态（若调用方异步处理）

## 8. 核心交互流程

1. 调用方在需要用户确认时打开本弹窗并传入配置。
2. 用户点击「确认」→ 调用方 `onConfirm` 回调 → 关闭弹窗。
3. 用户点击「取消」或关闭 → 调用方 `onCancel` 回调 → 关闭弹窗，不执行确认逻辑。

## 9. 展示的业务数据

- 无固定业务数据；仅展示调用方传入的文案配置。

## 10. 业务规则与约束

- **不得**在本通用弹窗内硬编码用户管理、问答、历史记录等业务字段。
- 须与私有化确认弹窗（如 C03 删除确认弹窗）区分：后者即使复用本组件，也须在外层封装业务专属信息区。
- PRD 未要求退出登录、新建会话等操作须二次确认；若实现阶段引入，应通过本通用弹窗调用，而非新建私有化弹窗（待确认）。

## 11. 异常与边界场景

- 同一时刻仅展示一个模态确认弹窗；重复打开应排队或替换（实现阶段确定）。
- 异步确认处理中应禁用重复点击确认按钮。

## 12. 待确认事项

- 除 C03 外，是否有其他业务场景须接入本通用确认弹窗（如新建会话清空上下文），PRD 未明确要求。
