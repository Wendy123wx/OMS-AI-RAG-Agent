# OMS智能问答系统需求文档

## 1. 登录页

### 1.1 登录方式

系统登录页支持两种登录方式：

- **钉钉登录**：扫码登录。
- **账号密码登录**：输入账号和密码登录。

初始化页面需显示账号密码信息。

### 1.2 测试账号

- 管理员账号：`admin`，密码：`12345678`
- 普通用户账号：`user`，密码：`12345678`

## 2. 工作台

登录进入系统后，工作台分为三大模块：问答平台、历史记录、管理后台。

### 2.1 问答平台

问答平台页面为上下结构：

- **上部**：显示问题和答案。答案携带文档的检索路径（来源）。
- **下部**：输入框，包含一个发送按钮。
  - 发送按钮点击后，可以终止（停止生成）。
  - 也可以取消发送。

### 2.2 历史记录

- 记录当前用户所涉及的查询历史，页面形式为列表页。
- 每条数据后有一个"查看"按钮，点击后展示：
  - 当时询问的问题
  - 记录的时间
  - 返回的文件路径
- 用户不可以删除，也不可以修改，只能查看。

### 2.3 管理后台

该模块仅管理员可见，普通用户不可见。侧边栏包含三个 Tab：

#### 2.3.1 用户管理

- 对普通用户的增删改查。
- 信息修改。
- 账号禁用等。

#### 2.3.2 统计看板

- 展示该系统的使用情况统计。

#### 2.3.3 查询记录

- 包含所有普通用户的查询记录。
- 需对查询记录做统计，展示高频搜索词汇，选取搜索频率前三名并置顶展示。

右上角提供"返回"按钮，点击后可回到工作台。

## 3. 通用功能

- 用户可以对密码进行修改或重置。
- 用户可以退出登录。
