### 3.2 Store 公开 API

Store 入口统一在 `src/stores/index.ts`（`export { useAuthStore } from './auth'` 等聚合导出）。以下签名为后续任务 **唯一可依赖** 的公开接口，禁止新增未列出的 state 字段（异步操作只放 actions，STATE-04）。

**`src/stores/auth.ts` — `useAuthStore`**（T00 建骨架，T01/T02/T09 使用，不得新建第二个鉴权 Store）
- state：`token: string | null`（持久化白名单）、`currentUser: UserAccount | null`（持久化 `accountId`/`role`/`username` 子字段，其余不落盘，STATE-05）、`isLoading: boolean`
- getters：`isAuthenticated: boolean`、`role: Role | null`
- actions：`login(username: string, password: string): Promise<void>`、`logout(): Promise<void>`、`changePassword(originalPassword: string, newPassword: string): Promise<void>`、`fetchCurrentUser(): Promise<void>`

**`src/stores/agentChat.ts` — `useAgentChatStore`**（仅 T03 消费/扩展内部逻辑，T01 的 C06 禁止依赖本 Store）
- state：`session: QaSession | null`、`messages: QaMessageVo[]`、`status: 'idle' | 'pending' | 'streaming' | 'done' | 'cancelled' | 'error'`（AGENT-04 单一状态机字段）
- getters：`isStreaming: boolean`、`canSend: boolean`
- actions：`startSession(): Promise<void>`、`newSession(): Promise<void>`、`sendQuestion(text: string): Promise<void>`（内部经 `composables/useSseStream.ts` 发起）、`cancelBeforeSend(): void`、`stopGeneration(): void`、`compressContext(): void`、`resetContext(): void`

**`src/stores/qaHistory.ts` — `useQaHistoryStore`**（T04）
- state：`records: QueryRecordListItemVo[]`、`currentDetail: QueryRecordDetailVo | null`、`isLoading: boolean`
- actions：`fetchHistoryList(): Promise<void>`、`fetchHistoryDetail(recordId: string): Promise<void>`、`clearCurrentDetail(): void`

**`src/stores/userManagement.ts` — `useUserManagementStore`**（T05）
- state：`users: UserAccountVo[]`、`isLoading: boolean`
- actions：`fetchUsers(): Promise<void>`、`createUser(params: CreateUserParams): Promise<void>`、`updateUser(accountId: string, params: UpdateUserParams): Promise<void>`、`disableUser(accountId: string): Promise<void>`、`restoreUser(accountId: string): Promise<void>`、`deleteUser(accountId: string): Promise<void>`

**`src/stores/auditLog.ts` — `useAuditLogStore`**（T06）
- state：`records: AccountOperationRecordVo[]`、`isLoading: boolean`
- actions：`fetchOperationRecords(): Promise<void>`

**`src/stores/dashboard.ts` — `useDashboardStore`**（T07）
- state：`snapshot: UsageStatisticsSnapshot | null`、`isLoading: boolean`
- actions：`fetchUsageStatistics(): Promise<void>`

**`src/stores/queryLog.ts` — `useQueryLogStore`**（T08）
- state：`records: QueryRecordListItemVo[]`（管理员全量视角，含 `askerUsername`）、`currentDetail: QueryRecordDetailVo | null`、`hotKeywords: HotKeywordVo[]`、`keyword: string`、`isLoading: boolean`
- actions：`fetchQueryLogs(): Promise<void>`、`searchByKeyword(keyword: string): Promise<void>`、`fetchQueryLogDetail(recordId: string): Promise<void>`、`fetchHotKeywords(): Promise<void>`、`clearCurrentDetail(): void`

**`src/stores/knowledgeBase.ts` — `useKnowledgeBaseStore`**（T10；C06 禁止 import 本 Store，见 §3.4）
- state：`documents: KnowledgeDocumentVo[]`、`isLoading: boolean`、`isUploading: boolean`
- actions：`fetchDocuments(): Promise<void>`、`uploadDocument(file: File): Promise<void>`

派生数据（如列表条数、是否为空）必须用 `getters` 计算，禁止在 state 中冗余存储（STATE-03）。

### 3.3 全局类型

统一放在 `src/types/`，字段命名与 `docs/prd/02-领域模型.md` 第2/3节聚合逐一对齐（TS-04）。核心类型（`src/types/qa.ts`）：

```ts
export type Role = 'user' | 'admin'
export type AccountStatus = 'normal' | 'disabled'

export interface UserAccount {
  accountId: string
  username: string
  email?: string
  avatar?: string
  role: Role
  status: AccountStatus
  createdAt: string
  updatedAt: string
}

export type AnswerSourceKind = 'knowledge_document' | 'order_query'

export interface HitSnippet {
  content: string
}

export interface SourceReference {
  kind: AnswerSourceKind
  locator: string           // 文档检索路径 / "订单系统实时查询"
  documentName?: string      // 仅 kind = knowledge_document 时存在
  hitSnippet?: HitSnippet     // 仅 kind = knowledge_document 时存在
}

export type GenerationStatus = 'pending' | 'streaming' | 'done' | 'cancelled' | 'error'
export type AnswerResultType = 'normal' | 'exception'
export type AnswerExceptionKind =
  | 'unrelated' | 'kb_miss' | 'kb_service_error'
  | 'order_no_result' | 'order_call_failed' | 'generation_failed'

export interface QaInteraction {
  interactionId: string
  question: string
  answer?: string
  sources: SourceReference[]
  status: GenerationStatus
  resultType?: AnswerResultType
  exceptionKind?: AnswerExceptionKind
  submittedAt: string
  completedAt?: string
}

export interface CompressedContext {
  summary: string
  coveredTurnCount: number
}

export interface QaSession {
  sessionId: string
  interactions: QaInteraction[]
  compressedContext?: CompressedContext
  createdAt: string
}

// 渲染层专用模型（AGENT-01），组件 Props 只消费本类型，不直接用 QaInteraction
export interface QaMessageVo {
  id: string
  role: 'user' | 'assistant' | 'system-notice'
  status: GenerationStatus
  content: string
  sources: SourceReference[]
  createdAt: number
}
```
