# 页面PRD：登录页

## 1. 页面信息

| 项目 | 内容 |
| --- | --- |
| 文件序号 | 01 |

| 页面名称 | 登录页 |
| 所属模块 | 身份认证 |

## 2. 页面定位与目标

登录页是系统的唯一入口页面，承担"未登录用户须先完成身份认证，方可使用系统能力"这一约束（PRD 5.1、9.1.1）。用户在此完成账号密码认证后进入工作台（PRD 5.1："登录成功后进入工作台"）。同时页面须保留钉钉扫码登录入口作为占位（PRD 5.1、1.3、第6节），并展示测试账号信息以支持演示验收（PRD 1.3 假设9、5.1）。

## 3. 使用角色与权限

- 本页面面向所有未登录访问者，不区分普通用户/管理员身份（身份在登录成功后才确定）。
- 页面本身不存在角色差异化视图；登录结果决定后续进入工作台后可见的能力范围（PRD 3 角色权限对照）。

## 4. 进入路径与导航关系

- **入口**：系统未登录状态下访问任意受保护能力时，均会被导向本页面（PRD 5.1）；退出登录也会返回本页面。
- **离开路径**：账号密码登录成功后，跳转至工作台，默认展示问答平台页（P02）。

## 5. 页面结构

布局对齐登录页简图：居中登录容器，**顶栏 Tab 切换**两种登录方式，下方为对应 Tab 内容区。

1. **登录方式 Tab 区**（顶栏）：「钉钉登录」「账号密码登录」两个 Tab，点击切换下方内容区（布局简图）。
2. **钉钉登录 Tab 内容区**（占位）：展示二维码占位区域；点击或进入后提示「功能开发中」，不建立真实登录会话（PRD 5.1）。
3. **账号密码登录 Tab 内容区**（本期可用）：
   - 账号输入（占位提示：「请输入账号」）
   - 密码输入（占位提示：「请输入密码」）
   - 「登录」提交操作
4. **测试账号提示信息区**：展示测试账号信息，供演示/验收（PRD 5.1）；可在账号密码 Tab 内容区内或容器底部展示。
5. **登录失败提示区**：呈现账号不存在/密码错误/账号已禁用等结果。

## 6. 关键组件清单

- 登录方式 Tab 切换（钉钉登录 / 账号密码登录）
- 钉钉登录 Tab 内容：二维码占位区（不做真实扫码交互，点击提示「功能开发中」）
- 账号密码登录 Tab 内容：账号输入、密码输入、「登录」提交操作
- 测试账号提示信息展示（`admin`/`user`，密码 `12345678`，PRD 5.1）
- 登录失败提示信息展示

## 7. 页面状态

- **初始态**：展示登录表单与测试账号提示信息、钉钉占位入口。
- **提交中态**：账号密码提交后等待认证结果。
- **登录成功态**：认证通过，跳转工作台。
- **登录失败态**：账号不存在（含已删除）、密码错误、账号已被禁用。
- **钉钉占位点击态**：点击钉钉登录入口后提示「功能开发中」或等价说明（PRD 5.1）。

## 8. 核心交互流程

依据 PRD 第8节使用场景1「登录场景」：

1. 用户打开系统，进入登录页；默认展示某一登录 Tab（待确认默认 Tab，建议默认「账号密码登录」以便演示）。
2. 用户可通过顶栏 Tab 切换「钉钉登录」（占位）或「账号密码登录」。
3. 在账号密码 Tab 下输入账号和密码，点击「登录」。
4. 系统校验：账号不存在或已删除 → 拦截；账号已禁用 → 拒绝；校验通过 → 建立登录会话，进入问答平台壳层（默认 P02）。
5. 若用户切换到钉钉登录 Tab 或触发占位交互，系统提示「功能开发中」，不建立真实登录会话。
6. 管理员新增的正式账号可直接使用初始密码登录，不要求首次强制改密。

## 9. 展示的业务数据

- `UserAccount.username`、`Credential`、`AccountStatus`、`LoginMethod`、`DingTalkIdentity`（占位）
- 测试账号信息（`admin`/`user`，密码 `12345678`）：PRD 5.1 演示信息

## 10. 业务规则与约束

- 未登录不能使用工作台能力（PRD 9.1.1）。
- 测试账号均可正常登录（PRD 9.1.2）。
- 登录页在所有环境展示测试账号提示信息（PRD 9.1.3）。
- 钉钉登录入口可见但不可用（PRD 9.1.4）。
- 管理员新增正式账号可使用初始密码直接登录（PRD 9.1.5）。
- 账号状态为「禁用」时不可建立新的登录会话（领域模型 3.1 不变量3）。

## 11. 异常与边界场景

- 账号不存在（含已被删除）、账号已被禁用、密码错误、钉钉占位点击不建立会话。

## 12. 待确认事项

- 登录页默认激活 Tab 为「账号密码登录」还是「钉钉登录」，PRD 未明确；建议默认「账号密码登录」以匹配本期可用能力。
