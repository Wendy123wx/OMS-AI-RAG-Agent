## 2. 页面定位与目标

用户管理列表页承载"管理员对普通用户账号进行新增、查看、修改、删除及禁用/恢复"的目标（PRD 5.5.1、5.5.2）。位于管理后台左侧菜单「用户管理」项下（PRD 5.9.1）。

**拆分依据**：列表 + 新增/编辑表单 + 删除确认。新增/编辑表单（C02）整合在本页统一管理；删除二级确认独立为 P04-02「06-前端-用户管理-删除确认页.md」，不单独建子目录。

## 3. 使用角色与权限

- 仅管理员可访问（PRD 3、5.9.2）。
- 仅可作用于「普通用户」角色账号（PRD 5.5.1、9.5.19）。

## 4. 进入路径与导航关系

- **入口**：管理员在问答平台壳层点击顶栏「管理后台」Tab 进入管理后台壳层，再点击左侧菜单「用户管理」（见总览 Q3 默认项待确认）。
- **离开路径**：左侧菜单切换 P06/P07；右上角「← 返回工作台」→ P02；「历史操作」→ P05；删除 → 打开 P04-02。

## 5. 页面结构

本页为**管理后台壳层**右侧内容区在「用户管理」菜单项下的视图；壳层结构见总览 §3.3。

1. **管理后台壳层顶栏**：标题「管理后台」；右上角「← 返回工作台」。
2. **管理后台左侧菜单**（与 P06/P07 共享）：用户管理（当前激活）| 统计看板 | 查询记录。
3. **用户管理内容区**（布局简图）：
   - **列表与操作区**：普通用户列表（用户名、邮箱、头像、状态、创建时间、更新时间）；新增、编辑、禁用/恢复、删除操作。
   - **右上角「历史操作」入口**（PRD 5.5.3）→ P05 操作记录列表。
   - **新增/编辑用户表单**（整合 C02，弹窗或区域内展开）：见 6.1。
4. **禁用/恢复操作**：针对列表单条记录执行，完成后列表即时刷新（PRD 5.5.2）。

## 6. 关键组件清单

### 6.1 新增/编辑用户表单（整合 C02）

**新增模式**：

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 用户名 | 登录唯一标识 | 是 |
| 用户邮箱 | 联系邮箱 | 否 |
| 用户头像 | 展示用头像 | 否 |
| 初始密码 | 新增账号登录凭证 | 是（见总览 Q1） |

**编辑模式**：

| 字段 | 可编辑 |
| --- | --- |
| 用户名 | 否 |
| 用户邮箱 | 是 |
| 用户头像 | 是 |

操作：确定提交、取消关闭。

## 7. 页面状态

- 正常态、空状态、新增表单展开态、编辑表单展开态、操作后即时刷新态

## 8. 核心交互流程

1. 浏览普通用户列表。
2. 新增：打开表单，填写用户名/邮箱/头像/初始密码，提交创建。
3. 编辑：打开表单，修改邮箱/头像，提交保存。
4. 禁用/恢复：即时刷新列表并记入操作记录。
5. 删除：打开 P04-02 删除确认页，二级确认后执行删除。

## 9. 展示的业务数据

- `UserAccount`：`username`、`Email`、`Avatar`、`AccountStatus`、`createdAt`、`updatedAt`
- `Role`：约束仅操作普通用户
- `Credential`：新增时通过初始密码设置

## 10. 业务规则与约束

- 不含管理员账号管理（PRD 9.5.19）。
- 禁用可恢复；删除须 P04-02 二级确认（PRD 9.5.21、9.5.22）。
- `username` 系统内唯一（领域模型 3.1 不变量2）。

## 11. 异常与边界场景

- 列表为空、用户名重复拦截、删除未完成确认不执行。
