# 页面PRD：提示弹窗（通用）

## 1. 页面信息

| 项目 | 内容 |
| --- | --- |
| 文件序号 | 14 |
| 页面编号 | G02 |
| 页面名称 | 提示弹窗（通用） |
| 弹窗类型 | **通用弹窗**（跨模块复用的单按钮信息提示容器） |
| 所属模块 | 通用组件 |
| 所属功能模块 | 不直接对应单一 PRD 功能点；为各页面信息提示提供统一交互模式 |
| 可访问角色 | 按调用方上下文决定 |
| 布局容器 | 全局弹窗层（由任意页面触发） |
| 典型调用方 | P01 钉钉占位提示（PRD 5.1）；P08 修改密码成功提示（可选，见 P08 待确认） |

## 2. 页面定位与目标

提供系统内统一的单按钮信息提示交互容器，用于向用户展示说明性文案并等待用户知晓后关闭。**不承载**表单输入或二值确认（确认类交互走 G01 确认弹窗）。钉钉扫码登录占位「功能开发中」为本弹窗的典型使用场景（PRD 5.1、9.1.4）。

## 3. 使用角色与权限

- 无独立访问入口；由父页面在需要展示信息提示时调用。
- 未登录与已登录场景均可使用（如 P01 钉钉占位）。

## 4. 进入路径与导航关系

- **入口**：业务代码调用打开，传入标题、提示文案、确认按钮文案（如「知道了」）。
- **离开路径**：用户点击确认/关闭后回到调用方上下文。

## 5. 页面结构

1. **标题区**：可配置标题（如「提示」）。
2. **内容区**：可配置提示正文（如「功能开发中」）。
3. **操作区**：单一确认/关闭按钮。

## 6. 关键组件清单

- 可配置标题、提示文案、确认按钮、关闭操作、遮罩层

## 7. 页面状态

- 关闭态、展示态

## 8. 核心交互流程

1. 调用方打开本弹窗并传入提示文案。
2. 用户阅读后点击确认/关闭。
3. 弹窗关闭，回到调用方页面，不产生路由跳转。

**P01 钉钉占位典型流程**（PRD 5.1）：

1. 用户在登录页切换到「钉钉登录」Tab 或触发占位交互。
2. 打开本弹窗，展示「功能开发中」或等价说明。
3. 用户关闭后仍停留在登录页，不建立登录会话。

## 9. 展示的业务数据

- 无固定业务数据；仅展示调用方传入的文案。

## 10. 业务规则与约束

- 钉钉占位提示须使用固定或等价文案「功能开发中」，不建立真实登录会话（PRD 5.1、9.1.4）。
- 轻量级操作结果反馈（如表单保存成功）实现阶段可选用本弹窗或 Toast；PRD 未强制，与 P08 等待确认事项联动。
- **不得**在本通用弹窗内承载需用户输入或二次确认的业务逻辑。

## 11. 异常与边界场景

- 同一时刻仅展示一个模态提示弹窗。

## 12. 待确认事项

- 除钉钉占位外，哪些成功/失败反馈须用模态提示弹窗而非页面内联提示，PRD 未逐一规定。
